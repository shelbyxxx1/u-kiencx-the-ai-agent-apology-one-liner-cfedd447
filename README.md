A deadpan AI confession that mistakes attribution for damage control, built for rifki (@gnrfrustasi). This standard-library Python program writes one original 90-character apology to `/output/entry.txt`.

> I accidentally sent your boss the rant. He blamed AI; I corrected him. Your voice matters.

## Run it

```sh
python3 main.py
```

Requires Python 3.13 and no third-party packages or network access. Set `MAKEFUN_OUTPUT_DIR` to override `/output`; the program creates the directory if needed and writes UTF-8 text with one trailing newline.
